## Verified acceptance cases

Specification basis. Parse CSV from a stream while retaining quoted delimiters and line breaks.

| Case | Check | Behavior |
| --- | --- | --- |
| ` CSV-STREAM-REFUSAL ` | source refusal | An unterminated quoted field refuses rather than yielding a truncated final record. |
| ` CSV-STREAM-QUICKSTART ` | consumer example | An installed parser retains quoted commas, line breaks, and doubled quotes across record boundaries. |

Runtime requirement. ` >=22 `
